# Kairos Visual System

## Principle

Kairos is not illustrated as a generic AI brain. It is represented as a control plane: connected knowledge sources, deliberate route selection, and one selected moment of action.

## Hierarchy

1. **Gold moment** — use once per surface, only for the selected or recommended action.
2. **Active cyan** — current routing, reading, or synthesis.
3. **Routing blue** — available knowledge and navigational structure.
4. **Ivory** — stable system structure and primary text.
5. **Muted blue-grey** — idle, secondary, or unavailable states.

## Typography

Use the macOS system stack. Recommended weights:

- Display: 650
- Headline: 600
- Body: 450–500
- Labels: 600
- Monospace paths and diffs: SF Mono / ui-monospace

## Surfaces

- Floating panel: 22 px radius
- Cards: 12–16 px radius
- Citation chips: fully rounded
- Avoid gradients on ordinary controls. Reserve them for the core Kairos identity and active routing.

## Icon discipline

- App icon may use depth, glass, and glow.
- Product icons must remain flat enough to read at 16–24 px.
- The gold point is not decorative. It means selected, complete, or action-ready.
- Do not place the gold point in every icon.
